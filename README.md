# 🎬 REEL ANALYTICS DASHBOARD

An interactive **Power BI dashboard** designed to analyze short-form Reel performance using **views, hook strength, retention, first-hour performance, content categories, music types, and monthly trends**.

---

## 📊 PROJECT OVERVIEW

This project transforms Reel performance data into **interactive and actionable insights** using **Microsoft Power BI, DAX, and Power Query**.

The dashboard contains **two analytical pages**:

- **Reel Performance Overview**
- **Reel Performance Insights**

---

## 📌 DASHBOARD PAGES

### 1️⃣ REEL PERFORMANCE OVERVIEW

The first page provides a **high-level overview of overall Reel performance**.

#### KEY METRICS

- **400 Reels**
- **195M Total Views**
- **486K Average Views**
- **0.58 Average Hook Score**

#### VISUALS INCLUDED

- **Total Views by Music Type**
- **Average Views by Category**
- **Average Hook Score by Category**
- **Total Views by Month**
- **Music Type Filter**
- **Category Filter**

---

### 2️⃣ REEL PERFORMANCE INSIGHTS

The second page provides a **deeper analysis of Reel performance** across categories and music types.

#### VISUALS INCLUDED

- **First-Hour Views by Category**
- **Retention Performance by Category**
- **Hook Strength by Music Type**
- **Total Views by Category**
- **Category × Music Type Performance Table**

This page focuses on **early performance, retention, hook strength, category performance, and music-type performance**.

---

## 🔥 KEY INSIGHTS

### 🎵 ORIGINAL MUSIC — 45.9M VIEWS

**Original music generated the highest total views** among the analyzed music types.

### 📅 MAY — 22.9M VIEWS

**May recorded the highest monthly total views** in the dataset.

### 👀 MOTIVATION — 571.63K AVERAGE VIEWS

**Motivation had the highest average views per Reel.**

### 🍔 FOOD — 25.95M TOTAL VIEWS

**Food generated the highest total views among content categories.**

### ⚡ TECH — 1.32M FIRST-HOUR VIEWS

**Tech had the strongest first-hour performance** among the analyzed categories.

---

## 💡 KEY FINDING

### TOTAL VIEWS ≠ AVERAGE VIEWS

**Motivation had the highest average views per Reel, while Food generated the highest total views.**

This shows why analyzing **multiple performance metrics** is important when evaluating Reel performance.

## 🎯 PROJECT OBJECTIVES

The dashboard was created to understand:

- **Which music types generate more views?**
